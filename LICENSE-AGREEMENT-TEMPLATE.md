# White-Label Source Code License, template

This is a starting point, not a finished legal document. Have an actual
lawyer review and adjust this before you use it for a real sale. It is
written in plain language on purpose so a lawyer can tighten it quickly,
not so it can skip legal review entirely.

### Notes for you (delete before sending)
- This is deliberately not a phone-home or technically enforced license,
  Section 2 is the actual protection, a legal agreement backed by the
  ability to sue for breach, not a check inside the code.
- If you plan to sell this to more than a handful of agencies, get a
  lawyer to turn this into a proper contract once, rather than reviewing
  every individual sale, it will be cheaper in total.
- Consider whether you want a standard contract for every buyer or are
  open to negotiating per deal, either is fine, just be consistent about
  which one you are doing.
